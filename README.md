# 잊혀진 숲의 전설 — 턴제 RPG

브라우저에서 바로 플레이할 수 있는 한국어 턴제 RPG입니다. **설치·빌드가 전혀 필요 없습니다.**
순수 HTML5 Canvas + JavaScript로 만들어져 외부 라이브러리 의존성이 없습니다.

## 바로 플레이하기

- **온라인(GitHub Pages):** 아래 주소에서 바로 플레이할 수 있습니다. (URL 대소문자 주의: `Mb-rpg`)
  - https://devgolol.github.io/Mb-rpg/
- **로컬에서:** `index.html` 파일을 더블클릭하여 브라우저로 열기만 하면 됩니다.

> 일부 브라우저에서 `file://` 보안 정책이 엄격할 경우, 폴더에서 아래 명령으로 간단한 로컬 서버를 띄워 접속하세요.
> ```bash
> python3 -m http.server 8000
> # 브라우저에서 http://localhost:8000 접속
> ```

## 게임 흐름

1. **타이틀** 화면에서 스페이스로 시작합니다.
2. **마을**에서 NPC와 대화하세요.
   - **촌장**: 게임 진행 힌트
   - **치유사**: HP·MP 완전 회복
   - **상인**: 포션·에테르 보급
3. **풀숲(진한 초록 타일)** 을 밟으면 마수와 **턴제 전투**가 시작됩니다.
   - 명령: `공격 / 스킬 / 아이템 / 도망`
   - 스킬: 강타, 화염구, 회복
4. 전투에서 이기면 **경험치·골드**를 얻고, 일정량이 쌓이면 **레벨업**(스탯 상승 + 완전 회복)합니다.
5. 충분히 강해지면 맵 위쪽 **붉은 성문**으로 가서 **보스 '어둠의 군주'** 에 도전하세요.
6. 보스를 쓰러뜨리면 **엔딩**, HP가 0이 되면 **게임 오버**(타이틀에서 재시작) 입니다.

## 파일 구조

```
index.html      진입점 (캔버스 + 스크립트 로드)
style.css       레이아웃 / 스타일
js/data.js      데이터: 스킬·아이템·몬스터·NPC 대사
js/player.js    플레이어 스탯 / 레벨업 / 인벤토리
js/map.js       타일맵 정의 / 렌더링 / 충돌·조우
js/battle.js    턴제 전투 엔진
js/ui.js        HUD / 전투·대화 화면 렌더링
js/main.js      게임 루프 / 상태 머신 / 입력
```
